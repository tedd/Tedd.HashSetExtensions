⚡ Bolt: List Iteration Optimization using CollectionsMarshal.AsSpan

**Hypothesis:** Iterating over `List<T>` using a standard `for` loop incurs bounds-checking overhead on every element access. By converting the list to a `Span<T>` using `System.Runtime.InteropServices.CollectionsMarshal.AsSpan(list)`, we can iterate over the underlying array directly, eliminating the bounds checks and improving performance.

**Execution:** Applied `#if NET5_0_OR_GREATER` directives in `ToHashSetExtensions`, `ContainsExtensions`, and `AddRemoveRangeExtensions` to iterate over `CollectionsMarshal.AsSpan(list)` when processing `List<T>` elements. This technique directly accesses the internal structure, yielding zero-allocation, boundary-check-free iterations.
